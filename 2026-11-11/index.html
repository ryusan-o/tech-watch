Claude Code v2.1.322
概要Claude Code v2.1.322 のチェンジログで、Vertex AI 経由で Claude Code を使う場合に fast mode が使えるようになりました。対象リージョンは global、us、eu です。Vertex 側が fast mode を拒否した場合は、エラーで止まらず通常速度(standard speed)に自動でフォールバックします。これまで fast mode は Anthropic 直接のAPI利用が中心でしたが、Google Cloud の Vertex 経由でも高速出力を選べるようになった、というアップデートです。
詳細を見る
活用案りゅうさんが普段 Anthropic のサブスクリプションや直接APIでClaude Codeを使っているなら、この変更の影響はほぼありません。効くのは、クライアント企業のセキュリティ要件でVertex AI経由の利用を求められる場面です。たとえばAIコンサルで『社内のGoogle Cloud契約の中でClaude Codeを使わせたい』という相談が来たとき、導入パッケージに『Vertex経由でもfast modeが使える(拒否されても標準速度に落ちるだけで止まらない)』と一言添えられます。使い方は、Vertex用の環境変数(CLAUDE_CODE_USE_VERTEX=1 など)を設定した状態で、セッション内の /fast を切り替えるイメージです。注意点として、fast modeは通常より単価が高い設定のことが多いので、Vertex側の料金表とクォータを確認せずに常用すると、クライアントの請求が想定外に増える可能性があります。フォールバックは黙って起きるため、速くなっていると思い込まない点も要注意です。
まず https://code.claude.com/docs/en/changelog の v2.1.322 の項目を開いて原文を確認してください。Vertex経由で使う案件が実際に出たら、公式ドキュメントのVertex AI設定ページで対応リージョンと料金を確認し、ターミナルで `claude --version` で2.1.322以上であることを確かめてから、セッション内で `/fast` を試してください。
