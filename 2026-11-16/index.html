Claude Code v2.1.325
概要Claude Code v2.1.325 のチェンジログです。今回の変更は小さく、VS Code などの統合ターミナル上で、Claude が Jupyter ノートブックを読んだり編集したりした後に、スピナー(処理中表示)のヒントとして「ノートブックのセルを再実行する」案内が一度だけ表示されるようになりました。対象はVS Codeおよび同様の統合ターミナルで、ノートブックに触れていない場合は表示されません。新しいコマンドや設定フラグの追加はなく、操作の気づきを促す軽微なUI改善です。
詳細を見る
活用案りゅうさんの普段の作業はClaude Codeでのリポジトリ運用や業務設計が中心で、Jupyterノートブックを日常的に使う場面は多くなさそうです。そのため直接の恩恵は小さく、基本は把握だけで十分です。効く場面があるとすれば、クライアント向けのAI業務診断で売上・予約データを簡単に集計したり、うま藻関連の数値をグラフ化したりするときに、VS Code上のノートブックをClaudeに編集させる流れです。その際、Claudeが書き換えたセルをユーザー側で再実行しないと画面上の結果が古いままになりがちですが、このヒントがその気づきを補ってくれます。自走支援で非エンジニアのクライアントにノートブックを渡すデモをする時も、操作の流れを説明しやすくなる可能性があります。注意点として、ヒントは一度きりの表示で、セルを自動実行してくれるわけではありません。結果を信用する前に、再実行して出力を確認する習慣は別途必要です。
試すなら、VS Codeの統合ターミナルで `claude` を起動し、適当な .ipynb ファイルを指定して「このノートブックのセルを1つ編集して」と依頼すると、スピナー表示にヒントが出るか確認できます。バージョンは `claude --version` で 2.1.325 以上か確認し、必要なら `claude update` を実行してください。詳細は https://code.claude.com/docs/en/changelog の該当バージョンの項目で読めます。

MCP: SudoMock
概要PulseMCPに「SudoMock」というMCPサーバーが掲載された。SudoMock APIを経由して、PSDテンプレートからフォトリアルな商品モックアップ(Tシャツ、パッケージ、マグカップ等の見た目合成)を生成する、と説明されている。MCPクライアント(Claude Code等)から、テンプレートに画像を差し込んでモックアップ画像を得る操作をツール呼び出しとして実行できる位置づけ。外部API(SudoMock)を使うため、APIキーの取得や利用プランは別途必要になる見込み。詳細な料金・対応ツール一覧は掲載ページ側で確認する必要がある。
詳細を見る
活用案商品パッケージやグッズの見た目確認が必要な場面で、可能性として役に立ちそうです。たとえばうま藻関連の商品ラベル、料理教室の配布物、りゅうさんちのオリジナルグッズなどで『実物を作る前に仕上がりイメージを共有したい』時です。手順としては、まずPSDモックアップテンプレートを1枚用意し、MCPサーバーとして登録(`claude mcp add` でSudoMockを追加)、デザイン画像を渡して書き出してもらう流れが考えられます。クライアント提案資料にパッケージ案を数パターン並べる用途にも向きそうです。一方で、外部APIで課金やレート制限があり得ること、未公開のデザインやクライアントの素材を外部サービスへ送ることになる点は注意が必要です。現状は優先課題に直結しないため、急いで導入するより、必要になった時の選択肢として把握しておく程度が妥当かもしれません。
https://www.pulsemcp.com/servers/sudomock を開き、必要なAPIキー、料金プラン、無料枠、提供ツール(テンプレート指定・画像差し替え・出力形式)を確認する。試すなら、公開済みで機密のない画像1枚だけを使い、`claude mcp add` でサーバーを登録して1回だけモックアップを生成し、品質とコストを見る。
