Claude Code v2.1.282
概要Claude Code v2.1.282 で、新しい設定 maxProseWidth が追加されました。幅の広いターミナルで、Claude が出力する文章(prose)の表示幅に上限をかけられる設定です。文章だけが対象で、テーブルとコードブロックは従来どおりターミナルの全幅を使って表示されます。ウルトラワイドモニターや全画面ターミナルでは1行が非常に長くなり読みにくかったため、その読みやすさを改善する変更です。changelog に記載された1項目の追加で、設定値の具体的な単位や既定値は上記の説明文からは分かりません。
詳細を見る
活用案ウルトラワイドや27インチ以上のモニターでターミナルを最大化して使うと、Claude の説明文が横に間延びして目が追いにくくなることがあります。そんなとき settings.json に maxProseWidth を入れて、文章だけ100文字前後に収める使い方が考えられます。表やコードは全幅のままなので、差分確認や比較表の見やすさは落ちません。長い提案や調査結果を読むことが多いりゅうさんの作業(議事録の要約確認、クライアント向け提案書の下書きレビューなど)で、読み疲れを減らせる可能性があります。日本語は全角で幅を取るため、英語と同じ数値感で設定すると狭く感じるかもしれません。まず少し広めの値から試して調整するのが無難です。ターミナルを小さめのウィンドウで使っているなら効果は出にくいので、その場合は無理に設定しなくて大丈夫です。
まず claude --version で v2.1.282 以降か確認し、古ければ更新します。その後 https://code.claude.com/docs/en/changelog の該当行と設定ドキュメントで maxProseWidth の値の形式(文字数か列数か)を確認してください。確認できたら ~/.claude/settings.json に追記して、ターミナルを最大化した状態で表示を見比べると効果が分かります。
