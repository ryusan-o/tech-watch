Claude Code v2.1.299
概要Claude Code v2.1.299で、環境変数 CLAUDE_CODE_DISABLE_FILE_MENTIONS が追加されました。これを設定すると、プロンプト内で @ を使ってファイルを指定したとき、ファイルの中身が自動で会話に展開されなくなります。代わりにClaudeには@で指したファイルのパスだけが渡され、中身が必要ならClaude自身がReadなどのファイル用ツールで読みに行く動作になります。従来は@メンションの時点で内容がコンテキストに入っていたため、大きなファイルや多数のファイルを指定するとコンテキストを大きく消費していました。今回の変更は、その展開をオプトインで止められるスイッチです。
詳細を見る
活用案効きそうなのは、巨大なログ、議事録の文字起こし、長いCSVやYAMLなどを@で指す場面です。中身が先に全部展開されるとコンテキストを圧迫しますが、パスだけ渡せばClaudeが必要な範囲だけ読みに行けます。たとえばMeetingMinutes関連の長いテキストや、複数ファイルをまとめて@指定する作業で、コンテキスト節約になる可能性があります。使い方は、settings.json の env に "CLAUDE_CODE_DISABLE_FILE_MENTIONS": "1" を入れるか、起動前にシェルで環境変数を設定する形が考えられます。値の書式は公式changelogで確認が必要です。注意点として、中身が自動で入らなくなるため、短いファイルでも毎回Readの1往復が発生し、かえって手間や遅延が増えることがあります。常時オンにせず、大きなファイルを扱う作業のときだけ試すのが無難かもしれません。
https://code.claude.com/docs/en/changelog を開いてv2.1.299の該当行を読み、値の書式を確認してください。そのうえで、PowerShellなら `$env:CLAUDE_CODE_DISABLE_FILE_MENTIONS="1"; claude` のように一時的に設定して起動し、大きめのファイルを@指定して `/context` でコンテキスト消費が通常時と変わるかを比べると、効果を体感できます。

Claude Code v2.1.300
概要Claude Code v2.1.300 のchangelogで、mod(Claude Codeの画面や挙動を拡張する仕組み)の「prompt decorations」に virtualText が追加されました。これはプロンプト入力欄の中に表示される文字で、下書き(draft)にも送信されるプロンプトにも一切入らない、表示専用のテキストです。これまでmod側でプロンプト欄に補助的な文字を出そうとすると、入力内容に混ざるリスクがありましたが、見た目だけの注釈やヒントを安全に重ねられるようになります。
詳細を見る
活用案りゅうさんがClaude Codeのmodを自作・導入する場面で効く可能性があります。たとえば、プロンプト欄に「今日のブランチ」「このリポジトリは本番VPSに触れる」「APIコストが今月上限の8割」といった警告やコンテキストを薄く表示しておけば、送信内容を汚さずに誤操作の抑止ができます。CodexとClaude Codeを共有リポジトリで使い分ける運用なら、現在のモードや注意点を常時表示するヒント欄としても使えそうです。実装は plugin-authoring スキル(mod作成用)を使い、prompt decorations に virtualText を指定する形が出発点になります。注意点として、これは表示専用でAIには渡らないため、AIに読ませたい指示の代わりにはなりません。必要な情報はCLAUDE.mdやrulesに置く使い分けが前提です。また、modの自作は優先順位の高い案件(クロージング優先)を押しのけてまで取り組むものではなく、困りごとが出てから触れば十分だと思います。
mod自作に関心が出たら、Claude Codeで /plugin-authoring を呼び出して prompt decorations の項目を確認し、virtualText の指定例を読んでください。あわせて https://code.claude.com/docs/en/changelog の v2.1.300 の記載原文も目を通しておくと、対応する設定項目名を正確に把握できます。
