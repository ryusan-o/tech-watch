Claude Code v2.1.312
概要Claude Code v2.1.312 の changelog に、Claude apps gateway 向けの設定 `oidc.user_id_claim` が追加されました。従来、gateway は OIDC の id_token の標準クレーム `sub` でユーザーを識別していましたが、この設定で別のクレームを識別子に指定できます。例として Microsoft Entra ID の `oid`(オブジェクトID)が挙げられています。組織の IdP の仕様に合わせて、ユーザー識別の軸を選べるようになる変更です。
詳細を見る
活用案これは主に、企業が Claude Code を gateway 経由で全社展開するときの管理者向け設定です。りゅうさんの現状(個人利用と少人数の共有リポジトリ運用)では、すぐ使う場面は多くないと思われます。効く可能性があるのは、AIコンサルで Microsoft 365 / Entra ID 環境のクライアントに Claude Code を導入する提案の場面です。Entra ID は `sub` がアプリごとに異なる値になるため、ユーザーの利用ログやコスト集計をアプリ間で突き合わせたいときに、不変の `oid` を識別子にできると便利です。導入設計書に「gateway の oidc.user_id_claim に oid を指定し、利用実績を社員ID単位で集計」と書ける、という程度の引き出しとして持っておくと提案に厚みが出ます。注意点として、途中で識別クレームを変えると既存ユーザーと別人扱いになる恐れがあるため、初期設計の段階で決めるのが安全です。
公式 changelog(https://code.claude.com/docs/en/changelog)の v2.1.312 の項を開き、`oidc.user_id_claim` の記述を確認してください。あわせて Claude apps gateway のドキュメントで OIDC 設定の節(設定ファイル上の書き方、未指定時の既定が `sub` かどうか)を読むと、クライアントへの提案時にそのまま使えます。

GitHub: Ryze-AI-Adgent/open-seo-mcp-skills
概要GitHub trendingに載った「Ryze-AI-Adgent/open-seo-mcp-skills」は、Claude向けの無料SEO用MCPサーバーと、オープンソースのSEO/GEOスキル集です。キーワード調査、順位トラッキング、サイト監査、被リンク分析、AI visibility(AI検索での露出度)の確認を、実際のGSC(Search Console)・GA4・広告データに基づいて行えるとされています。導入は `claude mcp add ryze --transport http https://connector.get-ryze.ai/mcp` の1コマンドで、HTTP経由のリモートMCPコネクタとして接続する形式です。GEO(生成AI検索最適化)まで範囲に含む点が特徴です。
詳細を見る
活用案りゅうさんの場合、AI経営コンサルの提案材料づくりが主な使い所になる可能性があります。たとえば、クライアントの飲食店や小規模事業者のサイトについて、GSCを接続して「どの検索語で表示されているのに順位が低いか」を洗い出し、改善提案書の根拠データとして出す、といった使い方です。りゅうさんち(予約制レストラン)や、うま藻関連サイトのGEO面、つまりChatGPTやPerplexityに店名・商品名がどう出るかの確認にも向きそうです。スキル部分はオープンソースなので、まず中身(プロンプトの手順)だけ読んで自前のスキルに取り込む形でも十分価値があります。注意点として、このMCPは外部のホスト型サーバー(get-ryze.ai)にGSC/GA4/広告アカウントの権限を渡す構成です。自社データなら判断しやすいですが、クライアントのデータで使う場合は、事前の同意と、運営元・データの取り扱い方針の確認が必要です。まずは自社サイトで試すのが無難です。
まずリポジトリ https://github.com/Ryze-AI-Adgent/open-seo-mcp-skills のREADMEとスキルのフォルダを開き、提供ツール一覧と、要求される権限(GSC/GA4/広告のスコープ)を確認してください。あわせて get-ryze.ai のプライバシーポリシーと利用規約でデータの保存・学習利用の扱いを読みます。問題なさそうなら、自社の検証用サイトだけを対象に `claude mcp add ryze --transport http https://connector.get-ryze.ai/mcp` を実行し、キーワード調査を1回試して出力品質を見てください。
