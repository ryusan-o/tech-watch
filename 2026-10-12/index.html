Claude Code v2.1.296
概要Claude Code v2.1.296 の変更履歴です。Claude appsゲートウェイの managed.policies[] に新しく `code` キーが追加されました。`code` は既存の `cli` と同じ設定項目を持ち、Claude Desktop の Code タブにも適用されます。`code` を desktop と併記すると、Claude Desktop のゲートウェイモードが有効になります。組織で管理するポリシーを、ターミナルのCLIとデスクトップアプリのCodeタブの両方へ同じ内容で配れるようになる変更です。
詳細を見る
活用案管理者がポリシーを一括配布するための機能なので、りゅうさんが1人で使う分には直接の出番は少ないです。効く可能性があるのは、AIコンサルでクライアント企業にClaude Codeを導入し、自走してもらう場面です。その際、権限の許可・拒否ルールやモデル制限などを `managed.policies[]` に一度書けば、CLIを使う人にもDesktopのCodeタブを使う人にも同じ統制をかけられます。導入標準パッケージに「ポリシー雛形」として組み込む案もあり得ます。たとえば `cli` と `code` に同じ設定を持たせ、Desktop利用者がいる場合だけ `code` と desktop を併記してゲートウェイモードにする、という運用です。注意点として、ゲートウェイモードが有効になると接続経路や挙動が変わる可能性があります。本番のクライアント環境へ入れる前に、検証用の環境で挙動を確かめるのが安全です。ゲートウェイ自体を使っていない現状では、導入は急がなくてよさそうです。
まず https://code.claude.com/docs/en/changelog を開き、v2.1.296 の該当項目を確認します。続けて同じドキュメントサイトで「managed.policies」や「Claude apps gateway」を検索し、`cli` と `code` の設定項目の違い、desktop 併記時のゲートウェイモードの条件を読みます。クライアントに管理者向けの統制が必要な案件が出たら、そのときに検証環境で試します。

Plugin: data-agent-kit
概要Googleが「Data Agent Kit」というプラグインを公開しました。Google Cloud上で作業するデータエンジニアやDB実務者向けの専門スキル群で、好みのコーディングエージェントに自然言語で指示するだけで使えます。できることは、複雑なデータパイプラインの設計、dbtによるデータ変換、SparkやBigQuery SQLのノートブック作成、GCPのデータ関連サービスをまたぐエンドツーエンドのワークフローの組み立てです。エージェントがGCPデータ基盤の専門アシスタントとして振る舞う位置づけです。
詳細を見る
活用案りゅうさんの現状では、GCPのデータ基盤を本格運用している場面は多くなさそうなので、今すぐ導入する類のものではないと思います。ただ、AIコンサルとして中堅企業のデータ活用を支援する場面で効く可能性があります。たとえばクライアントが「BigQueryにデータはあるが集計やパイプラインを組める人がいない」という状況で、ヒアリングの場でClaude Codeにこのプラグインを入れ、自然言語で『売上と予約データを日次で統合するパイプラインを設計して』と頼み、dbtモデルとBigQuery SQLの叩き台をその場で出して見せる、という「やってみせて自走させる」型のデモに使えそうです。AlgaleXのCRMや売上分析をBigQueryに寄せる構想が出た場合の試作にも使えるかもしれません。注意点として、本番データに接続するとGCPの課金や権限・個人情報の扱いが絡むため、最初はサンプルデータと読み取り専用権限のサンドボックスプロジェクトで試すのが安全です。
まず公式ページ https://cloud.google.com/products/data-agent-kit を開き、対応するコーディングエージェント(Claude Code対応の有無)とインストール方法、必要なIAM権限の記載を確認します。対応していれば、BigQueryの公開サンプルデータセット(bigquery-public-data)を使い、サンドボックス用の新規GCPプロジェクトで『このテーブルから月次集計のdbtモデルを作って』と試すのが低リスクな一歩です。
