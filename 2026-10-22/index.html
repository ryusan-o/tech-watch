Claude Code v2.1.307
概要Claude Code v2.1.307 のチェンジログで、新しいスラッシュコマンド `/claude-api api-version` が追加されました。このコマンドは、プロジェクト内の Claude API を呼び出すコードを API バージョン 2026-10-21 へ移行する用途のものです。従来は Anthropic のバージョン更新に合わせて、SDK の呼び出し、ヘッダー、パラメータの変更箇所を手作業で探して直す必要がありました。それを Claude Code に任せられる形になります。詳細な書き換え範囲はチェンジログの記載以上は確認できていません。
詳細を見る
活用案Claude API を直接叩いているコードを複数持っている場合に効く可能性があります。たとえば APICostPatrol や MeetingMinutes、Recipism のように、プロジェクトごとにモデル呼び出しが散らばっている構成です。API バージョン更新のタイミングで、リポジトリごとにこのコマンドを実行し、差分を確認してから取り込む使い方が考えられます。流れは、①対象リポジトリで Claude Code を起動する、②`/claude-api api-version` を実行する、③出てきた差分を目視レビューする、④既存のテストか実機の1回呼び出しで動作確認する、の順です。注意点として、移行は課金や顧客向け機能に直結する呼び出しを書き換える可能性があります。そのため、本番稼働中の VPS 上のコードに直接かけず、必ずブランチかコピーで試すのが安全です。また、対象バージョン 2026-10-21 の非互換変更はまだ把握できていないため、書き換え結果をそのまま信用せず、公式の移行ガイドと突き合わせる前提が望ましいです。
まず https://code.claude.com/docs/en/changelog の v2.1.307 の項で記載内容を確認し、あわせて Claude API の公式ドキュメントで 2026-10-21 バージョンの変更点(破壊的変更の有無)を読む。そのうえで、影響が小さいプロジェクトのコピーを1つ作り、そこで Claude Code を v2.1.307 以上に更新(`claude update`)して `/claude-api api-version` を試し、差分の量と内容を確かめる。
