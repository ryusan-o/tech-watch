Claude Code v2.1.293
概要Claude Code v2.1.293で、新モデル「Claude Haiku 5.5」(モデルID: claude-haiku-5-5)が追加されました。Anthropic APIにおけるHaikuの既定モデルになります。コンテキストは1Mトークンで、料金は説明文では「0.10/0.10/0.10/0.50 per Mtok」と記載されています。100Kトークン超のプロンプトでは「0.50/0.50/0.50/2.50」になります。4つの数値が何の単価の並びかは、原文からは読み取れません。Haikuは軽量・高速枠のモデルです。今回、長文脈への対応と低単価が同時に示されました。
詳細を見る
活用案Haiku 5.5は、毎回の精度よりも回数と速さが効く定型処理に向いている可能性があります。たとえば議事録の要約、クライアント問い合わせの分類、LINE Botの一次応答、レシピ生成の下書きなどです。Claude Codeでもサブエージェントや軽い調査だけをHaikuに回せます。設定は、エージェント定義のfrontmatterで model: haiku を指定するか、/model で切り替えます。上位モデルは設計判断や最終確認に残すと、利用量を抑えやすくなります。切り替える前に、既存の定型プロンプトを5〜10件ほどHaiku 5.5で流してみてください。出力品質を上位モデルと見比べる価値があります。注意点として、顧客の個人情報や対外的な最終文面は、安さを理由に任せず、人の確認を挟むほうが安全です。また100K超で単価が上がるため、長文を丸ごと渡す運用では、実コストを少量で測ってから判断すると安心です。
公式の変更履歴(https://code.claude.com/docs/en/changelog)でv2.1.293の項目を開き、Haiku 5.5の記述を確認してください。料金の4つの数値が何の単価なのかは、Anthropicの料金ページで照合できます。試すなら、Claude Codeで /model を開いてHaiku 5.5を選び、普段の軽い作業を1つ流して、品質と速度を確認してください。

詳細を見る
活用案活用の主眼は、検知回避を売りにする点を業務に使わないという線引きに置くのがよさそうです。「アンチボットに検出されない」仕組みは、サイトの利用規約や不正アクセス対策を迂回する用途と隣り合わせです。クライアント案件や自社の業務自動化に載せると、アカウント凍結や契約上の問題になる可能性があります。使えるとすれば、自分が管理するサイトや社内ツールの定型操作を自動化する場面に限られます。例えばりゅうさんち予約管理画面の入力や、自社CRMの定期チェックです。その場合も、検知回避機能は使わず、公式APIやPlaywrightなど正規の手段を優先する方が安全です。比較材料としては、セルフホスト型のブラウザ自動化エージェントの設計(ブラウザ操作、LLM呼び出し、ログの持ち方)を眺め、AI業務自動化診断の説明素材にする程度が現実的です。
