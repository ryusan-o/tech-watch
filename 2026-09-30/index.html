Claude Code v2.1.285
概要Claude Code v2.1.285 のチェンジログで、環境変数 CLAUDE_CODE_DISABLE_WEB_FETCH が追加されました。この変数を設定すると、Claude Code が URL の内容を取得する WebFetch ツールが無効になります。Webページの取得をツール単位で止められるため、外部サイトの内容をエージェントに読み込ませたくない環境や、プロンプトインジェクションのリスクを下げたい場面で、設定だけで制御できます。なお、この説明文から確認できるのは WebFetch の無効化のみです。WebSearch など他のツールへの影響は、説明には書かれていません。
詳細を見る
活用案顧客の情報が入るリポジトリで Claude Code を動かすときに、外部の任意ページを読み込ませない安全策として効く可能性があります。たとえばクライアント支援や CRM 関連の作業では、Webページに仕込まれた指示がエージェントに混入するのを避けたい場面があります。使い方の例は、.claude/settings.json の env に "CLAUDE_CODE_DISABLE_WEB_FETCH": "1" を書き、そのリポジトリだけ WebFetch を止める形です。無効化されたことは、Claude Code に「WebFetchを使ってURLを読んで」と頼み、実際に使えないことで確認できます。注意点として、値の書き方(1 か true か)は説明文に明記がないため、公式ドキュメントで確認してください。また、調べ物をさせる作業では WebFetch が使えないと不便なので、常時オフにせず、プロジェクト単位で切り替える運用が現実的です。
https://code.claude.com/docs/en/changelog を開いて v2.1.285 の項目を確認してください。あわせて、公式ドキュメントの環境変数一覧で CLAUDE_CODE_DISABLE_WEB_FETCH の設定値の書き方を調べます。試すなら、顧客データを扱うリポジトリの .claude/settings.json の env に追記し、Claude Code を再起動して WebFetch が拒否されることを確認します。

GitHub: blader/humanizer
概要GitHub Trendingに入った blader/humanizer は、「AI生成文の兆候をテキストから取り除く」ことを目的としたエージェント用スキルです。ChatGPT系の文章に出やすい定型表現や、過剰な強調、不自然な言い回し、機械的な構成といったパターンを検出し、人間が書いたような自然な文体へ書き直す指示をスキルとして提供します。Claude Codeなどのエージェントにスキルとして組み込み、文章の推敲工程で呼び出す使い方が想定されています。ここでは説明文のみを根拠にしており、具体的な検出ルールの数やインストール手順はリポジトリのREADMEで確認が必要です。
詳細を見る
活用案SNS投稿やブログ、提案書、メルマガなど、AIに下書きさせた文章を仕上げる場面で効く可能性があります。たとえばDevLogSNSやコンサル提案書の下書きをAIが作ったあと、最後の推敲ステップとしてこのスキルを通し、「〜と言えるでしょう」「重要です」の連発や、きれいすぎる三点列挙といったAIっぽさを削る使い方が考えられます。使い方の案としては、リポジトリのSKILL.mdを自分の.claude/skillsに置いて、「この下書きをhumanizerで直して」と呼ぶ形です。ただし本スキルは英語圏のAI文体を想定している可能性が高く、日本語には効きが弱いかもしれません。また、りゅうさん自身の声や価値観はbrand-voice.mdが正本なので、汎用の人間らしさ変換に任せると個性が薄まる恐れがあります。まず英語圏向けの発信や、日本語の実験用に1〜2本だけ試すのが安全です。「AIで書いたことを隠す」目的で顧客向けに使う場合は、開示方針との整合も先に考える必要があります。
ブラウザで https://github.com/blader/humanizer を開き、READMEとSKILL.mdの本文を読んで、検出パターンが英語前提か日本語にも通用するかを確認してください。試すなら、手元の下書き1本を用意し、スキルを一時フォルダに置いて適用前後を並べて比べる形が安全です。日本語の違和感が残る場合は、パターン部分だけを参考に、brand-voice.mdに沿った自前の推敲チェックリストへ移す道もあります。
