Claude Code v2.1.287
概要Claude Code v2.1.287のチェンジログに「Claude Mods」が追加されました。説明文によると、プラグインがこれまでより深いレベルでClaude Codeの挙動を変更できるようになる、という機能です。従来のプラグインはスキル、コマンド、フック、MCPなどを足す形が中心でしたが、Modsはその枠を越えて本体の動作に踏み込める位置づけです。ただし、公開されている説明は1行のみで、変更できる具体的な範囲、設定方法、権限モデル、フラグ名は確認できていません。詳細は公式チェンジログ(code.claude.com/docs/en/changelog)を見る必要があります。

活用案りゅうさんはCodexとClaude Codeを共有リポジトリで使い、.claude配下のルールやフックで運用を作り込んでいます。そのため、今は個別のrulesやhooks、settings.jsonに分散している「自分流の挙動」を、Modsとして1つのプラグインにまとめて持ち運べる可能性があります。たとえばクライアント導入時の標準パッケージに、安全ルールや出力スタイルを同梱して渡す使い方が考えられます。この「やってみせて自走させる」型の支援とは相性が良さそうです。一方で、深い挙動を書き換えられるということは、信頼できない第三者のModを入れた場合のリスクも大きくなります。ソースが不明なものは入れず、まず自分で書いたものか公式のものだけを、本番環境ではなく検証用のディレクトリで試すのが安全です。なお、中身が未確認の段階では導入を急ぐ必要はなく、現行運用で困っていなければ様子見でも問題ありません。
まず https://code.claude.com/docs/en/changelog を開き、v2.1.287の「Claude Mods」の項目と、そこからリンクされている解説ページを読みます。確認する点は、(1)Modで変更できる範囲、(2)プラグインとの設定方法の違い、(3)権限やセキュリティ上の注意、の3つです。あわせて、ターミナルで `claude --version` を実行して手元のバージョンを確認し、v2.1.287未満なら更新が必要かどうかも見ます。試す場合は、本番のリポジトリではなく空の検証用フォルダで行うのが安全です。

詳細を見る
活用案個人開発のプロダクトを公開するときの告知素材づくりに使える可能性があります。backlogにはDevLogSNSやSNS戦略、公開待ちプロダクトの枠があるので、出荷ゲートを通ったプロダクトの告知動画を、撮影や編集なしで試作する使い方が考えられます。たとえば小さなツールを1本作ったら、そのリポジトリでbragを実行し、出てきた15〜30秒の動画をXやInstagramの投稿案にします。りゅうさんの「全体設計してから小さく出す」「反応を見る」という流れの、反応を見る段階を軽くする位置づけです。クライアント向けの導入事例動画づくりにも転用できるかもしれません。注意点は2つです。1つ目は、コードやREADMEが外部の生成APIに送られる仕組みかもしれないことです。顧客情報や未公開の業務ロジックを含むリポジトリには、仕組みを確認するまで使わないほうが安全です。2つ目は、ブランド表現の調整が必要になりそうなことです。自動生成の文言はそのまま公開せず、brand-voice.mdの方針に沿って目で確認してから出すのがよさそうです。
ブラウザで https://github.com/latent-spaces/brag を開き、READMEの「Install」「Usage」の節で、①実行コマンド ②必要なAPIキーや外部サービス ③入力として読み込むデータ ④出力形式と長さ、の4点を確認します。外部送信がある場合は、公開済みで機密のない小さなリポジトリを1つ選び、そこでだけ実行して出来を見てください。顧客案件や未公開コードでは試さないでください。
