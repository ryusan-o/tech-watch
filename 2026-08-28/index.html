Claude Code v2.1.248
概要Claude Code v2.1.248で、セキュリティを強化する`--restricted`オプションが追加されました。これにより、コマンド実行やWebFetchなどの組み込みツールが制限され、ファイルアクセスはワーキングディレクトリ内に限定されるため、より安全な環境でAIによるコード実行が可能になります。
詳細を見る
活用案りゅうさんがAIコンサルティングでクライアントにClaude Codeの利用を提案する際、このオプションを活用することで、機密情報を扱う業務や外部連携を厳しく制限したいケースにおいて、より安全性の高い実行環境を提供できる可能性があります。社内でのAI活用におけるリスク管理にも役立つかもしれません。
深掘りするなら、`--restricted`オプションが具体的にどのようなシナリオで有効か、既存のAI活用プロジェクト（例: MeetingMinutes、WONDAY Growth Engine）にどのように適用できるかを調査する。

詳細を見る

MHSの進捗や、具体的なユースケースが発表された際に再度確認すると良いでしょう。
