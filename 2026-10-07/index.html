Claude Code v2.1.292
概要Claude Code v2.1.292 で、`claude plugin install` に `--marketplace <source>` オプションが追加されました。これまでは、マーケットプレイスを `claude plugin marketplace add` で登録してからプラグインをインストールする2段階の手順でした。新オプションを使うと、指定したマーケットプレイスが未登録なら追加し、そのままそこからプラグインをインストールします。マーケットプレイス追加時のポリシーチェックは `claude plugin marketplace add` と同じ条件で適用されます。
詳細を見る
活用案効きそうなのは、クライアント先やPCの新規セットアップなど、Claude Code環境を一から整える場面です。「マーケットプレイス追加→プラグインインストール」の2コマンドが `claude plugin install <plugin> --marketplace <source>` の1行にまとまるので、セットアップ手順書やスクリプトに書くコマンドが減ります。りゅうさんの「やってみせて自走させる」方針とも相性がよく、導入支援先に渡す手順を1行にできる可能性があります。社内で共通のプラグインを配る場合も、「このコマンドを貼るだけ」という形にできます。注意点として、マーケットプレイスの追加は外部ソースを信頼する行為です。ポリシーチェックは通常の追加と同じで、緩和されるわけではありません。出所不明のソースを1行で入れてしまわないよう、source の中身は事前に確認したほうが安全です。
次に新しい環境へプラグインを入れる機会に、これまでの2コマンドの代わりに `claude plugin install <プラグイン名> --marketplace <ソース>` を1回試せます。使い方は `claude plugin install --help` で確認できます。変更点の原文は https://code.claude.com/docs/en/changelog の v2.1.292 の項にあります。

Oct 6, 2026AnnouncementsExpanding the Cyber Verification Program
概要Anthropic は 2026年10月6日、Cyber Verification Program(CVP)を拡張しました。従来のCVPとProject Glasswingを統合し、3段階のアクセスにしています。①Defense Access は、インシデント対応、マルウェア解析、脆弱性の検証といった防御業務向けです。企業のセキュリティチーム、NPO、大学、OSSメンテナ、個人研究者も対象で、審査は数日です。②Red Team Access は、許可を得たペネトレーションテストやレッドチーム向けです。組織のみが対象で、審査は数週間かかります。③Specialized Access は、航空OSや電力網など安全性が重要なシステムの検証向けで、米政府と連携して審査します。対象モデルはOpus 5.5、Sonnet 5.5、Mythos 5.1などです。Defense Access では攻撃的タスクの約92%がブロックされます。一般提供モデルでは従来どおり厳しいブロックが残ります。申請は portal.anthropic.com/programs/cvp から行い、データ保持への同意が必要です。
詳細を見る
活用案りゅうさんが日常的に使うClaude CodeやAPIで、セキュリティ系の依頼がたまに拒否されることがあれば、Defense Accessが候補になります。例えば、クライアントに導入したLineBotやWebアプリの脆弱性確認、VPSの設定点検、不審なスクリプトの解析です。WONDAYとして、AI導入支援の納品前チェックを防御目的で行うのは筋が通ります。ただし対象は「セキュリティ業務をする組織・個人」で、申請には組織のセキュリティ統制の確認が要るため、通常業務の拒否を減らす手段としては合いません。Red Teamは組織限定で、WONDAYの現状には不要と思われます。また、Defense Accessでも攻撃的タスクの約92%はブロックされます。さらに、データ保持への同意が条件です。クライアントの個人情報や機密を扱う場面では、何を流すかを先に決めておく必要があります。現状でセキュリティ関連の拒否に困っていなければ、「そういう枠がある」と把握しておけば十分です。
困った場面が出たときに動けるよう、https://www.anthropic.com/news/cyber-verification-program の「Defense Access」の対象者・必要書類の項を確認してください。実際に申請するなら portal.anthropic.com/programs/cvp を開き、必要な「セキュリティ統制の確認」項目を見ます。その際、データ保持への同意がクライアント案件の契約や守秘義務と矛盾しないか、先に確認してください。VPSの点検がClaudeに拒否された時が、申請を検討する目安です。
