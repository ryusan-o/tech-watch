GitHub: gogs/gogs
概要gogs/gogsは、GitHubのトレンドに上がったセルフホスト型Gitサービスで、キャッチコピーは「The painless way to host your own Git service」(自前のGitサービスを手間なく立てる方法)。Go言語で書かれた軽量なGitホスティングで、Web UIからリポジトリ、Issue、Pull Request、Wikiを管理できる。単一バイナリで動き、低スペックなサーバーでも動かせる点が売りとされている。今回提示された情報はリポジトリの説明文とトレンド入りの事実のみで、新バージョンや新機能の詳細までは含まれていない。
詳細を見る
活用案自前のVPSにGitサービスを置くと、クライアント案件のコードやプロンプト、設定ファイルをGitHubに出さずに管理できる可能性があります。たとえばAIコンサルで納品する自動化スクリプトや、顧客の業務情報が混ざる設定を、WONDAY専用のプライベートな置き場にまとめる使い方です。手順は、小さなVPSにgogsのバイナリかDockerイメージ(gogs/gogs)を置き、SQLiteで初期設定し、リバースプロキシでHTTPS化するだけの構成が考えられます。Codex・Claude Codeの共有リポジトリのバックアップ先(ミラー)としても使えそうです。ただし、すでにVPSインフラに緊急度ありの項目があるため、新しい常駐サービスを増やすと運用負荷が上がります。セキュリティ更新を追い続ける覚悟がなければ、GitHubのプライベートリポジトリで足りるケースが多いです。同系統にはGiteaやForgejoもあり、更新の活発さではそちらが有利な場合もあるので、比較してからでも遅くありません。
https://github.com/gogs/gogs のREADMEとReleasesを開き、直近のリリース日とセキュリティ修正の頻度を確認する。続けて https://forgejo.org と https://about.gitea.com/ の更新状況も見て、更新が活発なのはどれかを比べる。試すなら手元で `docker run --rm -p 3000:3000 gogs/gogs` を実行し、http://localhost:3000 で初期設定画面の手間を確認する。

GitHub: FrigadeHQ/yogurt
概要FrigadeHQ/yogurtは、GitHubでトレンド入りしたオープンソースのAI議事録アプリ。説明文によると「会議メモがPC内にとどまるプライベートなAIノートテイカー」で、Granolaの無料OSS代替を名乗る。Mac・Windows・Linuxに対応する。録音や文字起こし、要約をクラウドに送らずローカルで完結させる設計で、会議データを外部に出したくない人向けの選択肢になる。説明文に書かれていない内部のモデル構成や要約の精度、日本語対応の可否は、このリポジトリで確認が必要。
詳細を見る
活用案りゅうさんはMeetingMinutes(議事録自動化)を運用中なので、比較対象や補完として使える可能性があります。使える場面は次の2つです。(1) 学童運営NPOなど、機密性の高い商談やヒアリングで『音声を外部APIに送らない』ことが条件になるとき。Whisper APIを使う現行フローが使いにくい案件向けに、ローカル完結の代替として提示できるかもしれません。(2) クライアントへの自走支援で、『Granolaの無料版として入れられるローカルツール』として紹介する使い方です。試すなら、Windowsで短い社内会議(AlgaleXの定例など)を1本録り、MeetingMinutesの出力と、固有名詞(日高栄祐、濱地心など)の認識精度、日本語の要約品質を見比べると判断しやすいです。注意点として、ローカル処理は端末の性能に依存するため、長時間会議で遅くならないか、日本語モデルが入っているかを先に確認してください。また、顧客の会議を録音する場合は同意取得が前提です。
ブラウザで https://github.com/FrigadeHQ/yogurt を開き、READMEの「対応OS」「使用する文字起こし/要約モデル」「日本語対応」「ライセンス」の4点を確認する。日本語が使えそうなら、リリースページからWindows版を入れ、5分程度のテスト録音で固有名詞の認識を試す。
