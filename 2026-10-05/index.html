Claude Code v2.1.288
概要Claude Code v2.1.288 のチェンジログで、mods(Claude Code内に自作のペイン・ステータスライン・フック等を載せるプラグイン機構)向けに `$.ui.selection()` が追加されました。フルスクリーンモードでユーザーが最後に選択したテキストを返し、選択範囲が1つのトランスクリプト行の内側に収まる場合は、その行の情報も合わせて返します。これまで mod 側からは画面上の選択内容を取得できませんでした。選択を起点にした操作を mod で作れるようになります。
詳細を見る
活用案画面で選んだ文言を起点に動く小さな mod を作る使い方が考えられます。たとえば長いログやエラーの一部をマウスで選び、そのまま「この部分だけ要約」「この文を議事録メモに追記」といったフックを走らせる形です。毎回コピーして貼り直す手間を減らせる可能性があります。手順は、plugin-authoring スキルで mod の雛形を作り、フック内で `$.ui.selection()` を呼んで返ったテキストと行情報を受け取り、既存の処理へ渡す流れです。選択が行をまたぐ場合は行情報が付かない点に注意が必要です。また fullscreen モード限定なので、通常表示では空になる前提で書く必要があります。mod は自作コードなので、顧客情報を含む画面を選択したまま外部へ送る処理は組まない方が安全です。今すぐ必要な機能ではなく、mod を触る機会があれば試す程度で十分と考えられます。
公式チェンジログ https://code.claude.com/docs/en/changelog の v2.1.288 の項で `$.ui.selection()` の記述を確認します。試すなら Claude Code で `/plugin-authoring` を呼び、フックから `$.ui.selection()` の戻り値をトーストに出すだけの最小 mod を作り、fullscreen で文字列と行情報が取れるかを確認します。

Claude Code v2.1.289
概要Claude Code v2.1.289 の変更履歴に、プラグインのコードペインで大きなファイルを開く速度を改善したという項目が載りました。変更点は、シンタックスハイライト付きのビューを最終的な表示幅で一度だけレイアウトする方式にしたことです。以前は幅が変わるたびに再レイアウトしていたとみられ、そのぶんの待ち時間が減ります。対象はプラグイン(plugin-authoring で扱うようなペイン表示)の中で大きなファイルを開く場面に限られます。通常のCLI操作やコード生成の挙動が変わる更新ではありません。
詳細を見る
活用案りゅうさんが普段の開発でClaude Codeを使うぶんには、直接の影響はほぼなさそうです。恩恵があるのは、プラグインやペイン表示を使って大きなログや生成物を眺める場面です。たとえばMeetingMinutesの長い議事録出力や、VPS上のログのような数千行のファイルをペインで開くときに、待ち時間が短くなる可能性があります。使い方は、Claude Codeを最新版に更新するだけで十分です。npm版なら `npm update -g @anthropic-ai/claude-code` で更新でき、`claude --version` で 2.1.289 以上か確認できます。設定を変える必要はありません。注意点として、今回の改善は表示速度に限られます。ファイルの読み取り量やトークン消費は変わらないので、大きなファイルをAIに読ませるコストを減らす効果は期待できません。プラグインのペインを自作・利用していない場合は、読み流して問題ありません。
ターミナルで `claude --version` を実行し、2.1.289 以上かを確認します。古ければ `npm update -g @anthropic-ai/claude-code` で更新します。変更履歴の全文は https://code.claude.com/docs/en/changelog の v2.1.289 の項目で読めます。大きなファイルをペインで開く機会があれば、前より速くなったかを体感で確かめる程度で十分です。
