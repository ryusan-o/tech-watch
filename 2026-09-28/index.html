Claude Code v2.1.283
概要Claude Code v2.1.283で、LLMゲートウェイ向けのヒントヘッダーに `x-claude-code-prompt-id` が追加された。これは1つのユーザープロンプトに対して実行される一連のリクエスト群を、ゲートウェイ側で1つのグループとして識別できるようにするIDで、環境変数 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` を設定することでオプトインで有効化される。デフォルトでは送信されない設定変更であり、既存の挙動には影響しない。
詳細を見る
活用案これは自社でLLMゲートウェイ(社内プロキシやAPIコスト管理層)を運用・監視している場合に効く機能で、りゅうさんの場合はAPICostPatrolのようなAPIコスト管理の仕組みと相性が良い可能性があります。具体的には、環境変数 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` を設定した状態でClaude Codeを起動すると、1回のプロンプト実行が裏で複数リクエストに分解されても、ゲートウェイ側のログで `x-claude-code-prompt-id` によって同一プロンプト由来のリクエストをグルーピング集計できます。これにより「1回の指示にどれだけコストがかかったか」を粒度細かく可視化する分析基盤を作る際の入力になり得ます。ただし、これは自前でゲートウェイ(プロキシサーバー)を構築・運用している場合にのみ意味を持つ機能で、Anthropic公式API/claude.aiを直接使っているだけなら恩恵はありません。
自社でLLMゲートウェイやプロキシを運用していないか確認し、もし今後APIコスト集計の仕組みを作るなら、`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` を環境変数に設定してヘッダーの中身を一度ログ出力で確認してみると良いでしょう。

GitHub: jub0t/Concat
概要Concatは、動画編集ソフトCapCutの代替を目指すオープンソース・クロスプラットフォームのプロジェクト「jub0t/Concat」。GitHubで公開されており、CapCut同様のカット編集・タイムライン操作などの機能を無料で提供することを狙う点が特徴。加えてMCP(Model Context Protocol)対応を謳っており、AIエージェントやツールから動画編集の操作を呼び出せる設計になっている可能性がある点が、通常の動画編集ソフトとは異なる。
詳細を見る
活用案りゅうさんちやAlgaleXのSNS投稿・レシピ動画、料理教室の告知動画など、短尺動画の編集作業がある場面で候補になりえます。CapCutは無料だが商用利用規約やデータの扱いが不透明な部分があるため、オープンソースでローカル完結できる代替があるのは、顧客提供物や社外秘素材を扱う際の選択肢として意味があります。MCP対応という点が本命で、もし実際にMCPサーバーとして動画編集操作(カット・字幕挿入・書き出し等)を公開しているなら、Claude Codeから「この素材をカットして書き出して」のように編集フローの一部を自動化できる可能性があります。ただし現時点ではプロジェクトの成熟度・安定性・実際のMCP機能の範囲が未検証なので、本番の顧客向け動画にいきなり使うのではなく、まずは社内の試し撮り素材やSNS用の軽い編集で試すのが無難です。
手が空いた時にhttps://github.com/jub0t/Concat のREADMEを開き、対応OS・MCPサーバーとして公開されている機能一覧・開発の活発さ(Star数、直近コミット日)を確認する。実用に足りそうならローカル環境にインストールして、SNS用の短い動画素材でカット編集を試してみる。

GitHub: irinabuht12-oss/marketing-skills
概要GitHubリポジトリ「marketing-skills」が公開され、Claude Code/claude.ai向けのマーケティング特化スキル49個が無料公開されました。Google Ads、Meta Ads、SEO、AI visibility(AI検索での言及・表示対策)などの領域をカバーするスキル集です。加えて、Ryze社が提供するGoogle Ads MCPサーバーとMeta Ads MCPサーバーも紹介されており、`claude mcp add ryze --transport http https://connector.get-ryze.ai/mcp` の1コマンドでClaude CodeにMCP接続を追加し、Claude経由でGoogle Ads/Meta Adsのデータ取得や操作ができるようになる、という内容です。
詳細を見る
活用案うま藻/AlgaleXの推販先開拓やDevLogSNSの運用、WONDAY Growth Engineの診断メニューに「広告運用の型」を組み込みたい場面で候補になりそうです。49スキルはSKILL.mdの形で配布されているはずなので、まずはリポジトリをclone(または該当スキルだけダウンロード)して`.claude/skills/`配下に置き、SEOやAI visibility系のスキルをりゅうさん自身のコンサル資料作成や診断チェックリストの下敷きとして読む、という使い方が軽くて安全です。一方、Ryze MCP(`claude mcp add ryze --transport http ...`)は外部の第三者サーバーにGoogle Ads/Meta Adsの広告アカウント接続を許可する形になるため、クライアントの広告アカウントに繋ぐ前提だと個人情報・アクセス権限・課金操作のリスクが伴います。導入するとしても、まず自分のテスト用アカウントか、権限を絞った状態で動作確認してからクライアント案件に持ち込む、という順序が安全だと考えられます。
https://github.com/irinabuht12-oss/marketing-skills を開き、READMEでスキル一覧とSKILL.mdの構成を確認する。気になるスキル(SEO/AI visibility系など)があればそのフォルダだけ読んで内容を確認し、Ryze MCPについては connector.get-ryze.ai の提供元情報とプライバシーポリシーを確認してから接続の是非を判断する。
