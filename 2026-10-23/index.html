Claude Code v2.1.309
概要Claude Code v2.1.309 の変更履歴です。主な変更は2点あります。1つ目は、Claude Code が自分自身のために実行する多くの git コマンドが Windows 上で高速化されたことです。2つ目は、それらのコマンドで起きるエラーが、git のロケール設定が他言語でも全プラットフォームで英語表示になることです。ユーザーが手で打つ git コマンドは対象外で、Claude Code が内部で呼ぶ git 処理(状態確認や差分取得など)が対象です。
詳細を見る
活用案りゅうさんの実行環境は Windows 10 なので、高速化の恩恵を直接受けやすいアップデートです。特にリポジトリが大きい場合や、Codex と共有している複数のリポジトリで作業する場合に、セッション開始時やファイル編集のたびに起きる待ちが短くなる可能性があります。体感の変化は、作業中の「もたつき」が減るかどうかで見られます。 エラーの英語固定は、日本語ロケールの git だと日本語メッセージが混ざり、AI がエラーを誤読したり、エラーの種類を判定できなかったりする問題を減らす狙いがあると考えられます。自動化フックやスクリプトが git の出力文字列を grep している場合は、英語固定で判定が安定する可能性があります。 注意点として、更新後に git 関連の挙動が変わっていないか、最初の数セッションは様子を見るのがよいでしょう。自分で書いた git ラッパーが日本語の出力に依存している場合は、あらかじめ確認が必要です。
ターミナルで `claude --version` を実行して 2.1.309 以上か確認します。古ければ `claude update` で更新します。変更内容の原文は https://code.claude.com/docs/en/changelog の v2.1.309 の項で読めます。更新後、大きめのリポジトリで普段のセッションを開き、起動やコミット作業の待ち時間が前より短いかを確認します。

Donating Agent Skills to the Agentic AI Foundation
概要Anthropicは、Claudeのエージェント機能で使われてきた「Agent Skills」を、Agentic AI Foundation(AAIF)へ寄贈すると発表しました。Agent Skillsは、SKILL.mdと補助ファイルをフォルダにまとめ、エージェントが必要な時だけ読み込んで手順やノウハウを再利用する仕組みです。今回の発表は、この仕様の管理をAnthropic単独から中立的な財団へ移すものです。目的は、特定ベンダーに閉じない共通フォーマットにすることだと読めます。なお取得できた情報はタイトルとURLのみで、仕様の変更点や移管の条件といった詳細は未確認です。
詳細を見る
活用案りゅうさんはCodexとClaude Codeを共有リポジトリで使っているので、同じスキル資産を両方で使い回せる方向に進む点が効く可能性があります。たとえば議事録の整形、見積書のチェック、クライアント導入の標準手順のように、毎回プロンプトで説明している「型」をSKILL.md(説明文+手順+参照ファイル)として1つ作っておく使い方です。寄贈後は仕様が安定し、他社ツールも対応しやすくなると期待できます。クライアント向けには、導入後に残る成果物を特定ツール専用ではなく「持ち運べるスキル」にすると、自走支援の方針とも合います。注意点は、スキルに顧客情報やAPIキーを書き込まないことです。また、他ツール側の対応状況は実際に読み込ませて確かめるまで前提にしない方が安全です。
まず元記事(https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)を開き、寄贈の範囲(仕様のみか、実装やサンプルも含むか)とAAIFの参加企業を確認してください。次に、日常で繰り返している手順を1つ選び、フォルダを作ってSKILL.md(冒頭にnameとdescription、本文に手順)を書きます。それをClaude Codeで呼び出し、Codex側でも同じフォルダを読めるか試すと、相互運用の現状が体感できます。
