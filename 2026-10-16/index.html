Claude Code v2.1.301
概要Claude Code v2.1.301で、環境変数 CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS が追加されました。無人実行向けのリトライモード(CLAUDE_CODE_RETRY_WATCHDOG)では、利用上限に達するとリセットまで待って再試行を続ける挙動でした。新しい変数にミリ秒で上限を設定すると、リセットまでの待ち時間がその値を超えるリクエストは、待たずに終了します。たとえば次のリセットが数時間先の場合に、いつまでもプロセスが居座るのを防げます。
詳細を見る
活用案夜間バッチや定期実行でClaude Codeを無人で回しているときに効く可能性があります。たとえば CLAUDE_CODE_RETRY_WATCHDOG=1 を付けた自動処理で使用量上限に当たると、これまでは数時間後のリセットまで待ち続け、タスクスケジューラのジョブが詰まったり、後続の処理が止まったりしえました。そこで CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS=900000(15分)のように設定すると、短い待ちなら粘り、長い待ちなら失敗として終了するので、呼び出し側のスクリプトが終了コードを見て通知や翌朝の再実行に切り替えられます。Windowsなら実行バッチ内で set して渡す形が考えられます。注意点として、上限を短くしすぎると、少し待てば再開できた処理まで打ち切られる点があります。まずは想定リセット間隔より少し短い値から試すのがよさそうです。手動で対話的に使う場面では影響がありません。
公式の変更履歴 https://code.claude.com/docs/en/changelog の v2.1.301 の項目を開き、CLAUDE_CODE_RETRY_WATCHDOG 系の説明と、打ち切り時の終了コードやメッセージを確認してください。無人実行のジョブがある場合は、ジョブ側の環境変数に値を1つ追加して、上限に当たった時の挙動を確かめられます。

Oct 15, 2026AnnouncementsAn update on independent evaluators
概要Anthropicが2026年10月15日、第三者評価機関の位置づけを更新した。非営利のAI評価機関METRの6名に、社用PC、オフィス、社内ツールを備えた「従業員に近いアクセス」を与え始めた。METRはリスク評価を公表する。Anthropicによる公表拒否権はない。ただし顧客データ、弁護士秘匿情報、モデルアーキテクチャ情報は、黒塗りを求められる。アクセスは3段階になる。Tier1は限定調査で、公表にAnthropicの承認が必要。Tier2は公表に承認が不要。Tier3がMETR型。SecureBioは2026年8月のRisk Reportの化学・生物兵器章をレビューする。AccentureとFacultyは、モデル評価とレッドチーミングで協業を計画している。Hugging Faceは協議の初期段階にある。製品、API、価格の変更はない。
詳細を見る
活用案製品の機能変更ではないため、直接の作業は発生しません。使い所は、クライアントへのAI導入提案で「このモデルを使って安全か」を問われた場面です。たとえばPUMPGYMや学童NPOのような、個人情報を扱う可能性のある相手です。その際、独立評価者の評価枠組みを根拠として紹介できる可能性があります。具体的には、METRなどが公開するレポートを、ベンダー選定資料の「第三者による検証状況」の欄に、出典付きで一行引用する形です。注意点が一つあります。公表物は黒塗りを含み、アーキテクチャ情報などは出ません。「第三者が全部見て保証した」とは書かず、「独立評価者が公表した範囲では」と限定して書く必要があります。Anthropic側の説明であり、評価結果そのものではない点も区別が必要です。
METRの公式サイト(metr.org)の公開レポート一覧を開き、Anthropicのモデルを扱った評価が出た時点で、結論部分だけ読む。現時点で何かを実装する必要はない。クライアント向けのAI選定資料を作る機会があれば、その時に出典として使えるよう、元記事のURL(https://www.anthropic.com/news/an-update-on-independent-evaluators)をブックマークしておく。
